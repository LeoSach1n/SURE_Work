# J.J. Thomson e/m Simulation

A lightweight, interactive web simulation of the historical J.J. Thomson Cathode Ray Tube experiment. Built to demonstrate the principles of electromagnetism, electron kinematics, and velocity selection in real-time.

## ✨ Features
* **Dual-Camera Perspectives:** Seamlessly toggle between a side-profile view of the apparatus and a front-facing Oscilloscope target.
* **Real-Time Physics Engine:** Adjust accelerating voltage, magnetic (B) fields, and electric (E) fields to dynamically manipulate the electron beam.
* **3D Tube Rotation:** Rotate the CRT apparatus to observe beam deflection across the full X-Y plane.
* **Experimental Calculator:** A built-in validation tool to manually calculate the e/m ratio and error percentage using live sensor data.
